# Expressions and control flow

[Documentation](index.mdx)

```zep
var total = do {
    var first = 10
    first + 20
}

var magnitude = if (total < 0) { -total } else { total }

var sign = when {
    (total < 0) -> -1,
    (total > 0) -> 1,
    else -> 0,
}
```

Blocks produce their final value. Conditions require booleans; branch values must be compatible.
`return` has type `never` and exits without contributing a branch value.

```zep
var label = when (shape) {
    Shape::Point -> "point",
    Shape::Circle { radius } if (radius > 10.0) -> "large circle",
    Shape::Circle { radius } -> "circle",
}
```

`when` evaluates its subject once and checks arms in order. Guards run after matching.
An `else` arm is last; complete unguarded enum/boolean coverage can omit it. Payload bindings
borrow original fields and preserve mutability. Reading into an owner copies; explicit moves act
on the field. Temporary subjects survive the full expression. String/range matching is not supported.

```zep
while (remaining > 0) {
    remaining = remaining - 1
}

for (var mut index = 0; index < 10; index = index + 1) {
    consume(index)
}
```

Loops are void statements. C-style `for` requires all three clauses. Collection iteration,
ranges, `break`, and `continue` are not implemented.

Closures use `{ value -> value + 1 }` or typed parameters; expected function types supply context.
Capturing closures currently support direct invocation. Struct literals use `Name { field: value }`.
`value as Type` converts, and `value is Type` checks a type. See [operator precedence](syntax.mdx).
