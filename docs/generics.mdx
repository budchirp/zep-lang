# Generics and interfaces

[Documentation](index.mdx)

```zep
fn identity<T>(value: T) -> T {
    return value
}

struct Container<T> {
    public:
        var value: T
}

var inferred = Container { value: 42 }
var contextual: Container<i64> = Container { value: 42 }
```

Arguments and expected result types provide inference. Explicit forms include `identity<i32>(42)`
and `Container<T: i32> { value: 42 }`. Unconstrained factories need context or explicit arguments.
Repeated parameters must infer the same type; unrelated numeric types are not merged.

Constraints use `<T: Constraint>`. Integer/float constraints accept their numeric families;
specialization preserves concrete width and signedness. Bindings use declaration identity.
Const-parameter inference, partial `_` arguments, and result-driven overload selection are unsupported.

## Interfaces

```zep
interface Reader {
    public:
        fn read() -> *mut u8
}

interface ReadWriter : Reader {
    public:
        fn write(data: *u8) mut -> void
}
```

Interfaces contain public signatures and may inherit interfaces. Structs list implemented interfaces
and supply matching `override fn` methods. Ordinary receivers borrow immutably; `mut` permits mutation.
Interface values use dynamic dispatch. Implementations must match full signatures, including
normalized [checked-error sets](errors.mdx).
