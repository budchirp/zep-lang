# Zep documentation

Zep compiles to native code through LLVM. Its resource model combines explicit allocation,
references, copy/move operations, deterministic destruction, and checked typed errors.

## Using the language

- [Getting started](getting_started.mdx): build the compiler and run the examples.
- [Lexical syntax](syntax.mdx): keywords, literals, and operators.
- [Types](types.mdx): primitive and composite types, conversions, and facade methods.
- [Declarations](declarations.mdx): variables, functions, structs, enums, and visibility.
- [Modules](modules.mdx): imports, exports, and source layout.
- [Expressions and control flow](expressions.mdx): blocks, matching, loops, and closures.
- [Generics and interfaces](generics.mdx): inference, constraints, and dynamic dispatch.
- [Ownership and memory](memory.mdx): references, special members, allocation, and cleanup.
- [Checked errors](errors.mdx): throwable structs, propagation, handlers, and callbacks.
- [Testing](testing.mdx): named tests, sibling access, and isolated execution.
- [Standard library](stdlib.mdx): text, collections, I/O, resources, and HTTP.
- [FFI and attributes](ffi.mdx): external declarations, ABI boundaries, and compiler attributes.
- [Projects and commands](projects.mdx): manifests, build options, and installation.
- [Editor support](editor.mdx): language-server features and extension configuration.
